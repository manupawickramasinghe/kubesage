Live demo on a real Kubernetes cluster: a desktop and a laptop

Pay for what you use. Fix what breaks.

KubeSage is an AI SRE team for Kubernetes. It finds capacity you pay for and don't use, diagnoses live incidents and writes each fix as a git commit. Every finding must cite real data, guardrails check every change, and a person decides what reaches the cluster.

Nine steps: two acts and a wrap-up, about six minutes. A caption bar at the bottom of each screen explains what it shows.

Why it's different

Evidence, or it's dropped.

Every finding cites a signal an agent collected. Guardrails reject actions with no evidence, unknown targets, machine types outside the catalog and requests bigger than a real node, and the model gets one retry with the reasons.

Small models do the legwork.

Four sub-agents gather evidence on a small, fast model; only the Thinker uses the large one. An incident run costs a few cents, and a full right-sizing analysis about one cent.

People stay in charge.

Every change is a git commit on its own branch, ready as a pull request. The web shell is read-only, the tmux view is a mirror, and nothing reaches the cluster until someone presses Apply.
